## 🆘 If Something Goes Wrong

### Build Fails
1. Check Actions tab for error
2. Read error message carefully
3. Most common: permissions not set
4. Solution: Settings → Actions → Read and write permissions

### Site Shows 404
1. Wait 10 minutes (first deploy takes longer)
2. Clear browser cache (Ctrl+Shift+R)
3. Verify GitHub Pages enabled
4. Check astro.config.mjs has correct base path

### Images Don't Load
1. Verify files in public/assets/
2. Check paths start with /assets/
3. Ensure file names match exactly
